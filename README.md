# SurveyScope — 问卷数据一键分析平台（出版级全图表与可编辑报告升级版）

面向问卷调查与市场研究的在线数据分析平台，将 SPSS 专业统计分析、The Economist / Pew Research 出版级信息设计与咨询公司汇报级可编辑 PPTX/Word 报告封装为零编程门槛的 Web 工具。

## 一、核心特性与十大功能章节

1. **多主题出版级视觉系统 (`theme.py`)**
   - 内置 5 套完整主题：**`暖纸杂志`**（默认 `#F7F2EA`）、**`墨蓝学术`**、**`纯白极简`**、**`深空夜读`**（深色模式 `#1E242E`）、**`薄荷清新`**。
   - 全部 5 套主题的标题、正文与强调色均满足 **WCAG AA 无障碍对比度 ($\ge 4.5:1$)**，切换主题同步作用于 Streamlit 界面、全部图表、PPTX 与 Word 报告。

2. **48 种图型（49 张样板图 + 2 张扩展文本图）与四件套导出 (`charts_*.py`, `chart_utils.py`)**
   - 完整实现样板包全部 49 张图表（`01-棒棒糖图` 至 `48-双轴组合图`，含 `08a-箱线图` 与 `08b-小提琴图`）及扩展文本图（`49-高频词共现网络图`、`50-情感分布图`）。
   - 每张图固定遵循四层视觉结构（口径副标题 → 动态结论主标题 → 图表主体 → 统计检验与出处脚注），并提供四件套下载：
     - **高清 PNG**（`2640×1485 px`，宽度 $\ge 2400\text{px}$，主题色不透明底色）
     - **可编辑矢量 SVG**（`svg.fonttype = 'none'`，完整保留 `<text>` 节点，可在 Illustrator / Figma / PowerPoint 中解组编辑）
     - **源数据 CSV**（`UTF-8-SIG` 编码，双击 Excel 直接打开不乱码）
     - **矢量 PDF**（适合学术论文排版插图）

3. **手动格式面板与 AI 自然语言改图助手 (`ai_edit.py`)**
   - 每张图表下方配备折叠式格式面板，支持修改主/副标题、排序方向、Top N 筛选、配色切换、特定项高亮、均值/中位数/自定义参考线与字号缩放。
   - 支持自然语言 AI 改图（如「把安徽标红」「按降序排」「只看前5名」），严格执行 14 项白名单 JSON Schema 校验，包含 5 步撤销历史栈与一键重置，严禁篡改任何底层统计数值与显著性。

4. **全链路统计分析与专项模型 (`stats_utils.py`)**
   - 完整覆盖描述统计、卡方检验与列比例 $z$ 检验、Welch $t$ 检验与单因素 ANOVA（含事后检验与效应量）、Cronbach's $\alpha$ 与探索性因子分析 (EFA)、多元线性回归与二元 Logistic 回归、随机森林与决策树规则、K-Means 聚类画像、事后分层加权。
   - 市调特色专项：品牌转化漏斗、桑基流转矩阵、对应分析双标图 (`prince.CA`)、IPA 重要性-满意度四象限、Van Westendorp 价格敏感度 (PSM)、**结构方程路径模型 (SEM, S1)**、**KANO 需求分层模型 (S2)**、**联合分析效用与相对重要性 (Conjoint, S3)**、**Albers 等积圆锥投影区域分布地图 (`china_provinces.geojson`)**、开放题高频词共现网络与情感分析。

5. **出版级双轨可编辑 PPTX 与 Word 报告 (`ppt_report.py`)**
   - 16:9 宽屏 PPTX（共 27 页，固定涵盖 7 类咨询报告版式），同时包含 **9 个原生 PowerPoint 图表 (`ppt/charts/chart*.xml`)**、**14 个内嵌矢量 SVG 图表 (`ppt/media/*.svg`)** 及 **20 页含 Markdown 源数据表的备注页 (Slide Notes)**。
   - Word 报告同步跟随当前主题配色，并在文末自动生成 **「第四章：图表源数据附录」**。

## 二、运行与验收自检

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行全量基准自检（A1–A18 与 S1–S8 共 26 项）
python self_check.py --stage all

# 3. 启动 Web 平台
streamlit run app.py
```
