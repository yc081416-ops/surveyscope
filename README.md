# SurveyScope — 问卷数据一键分析平台（Round 4 产品化正式版）

面向问卷调查与市场研究的在线 SaaS 统计分析与出版级可视化平台，将 SPSS 专业统计检验、The Economist / Pew Research 信息设计规范与咨询公司级可编辑 PPTX / Word 报告整合为零编程门槛的在线工作台。

## 一、核心架构与产品特性

1. **正式产品化流程与自适应能力引擎 (`app.py`, `stats_utils.py`)**
   - **冷启动正式落地页**：无任何预置演示数据或虚拟指标；支持拖拽上传 CSV（自动探测 UTF-8 / UTF-8-SIG / GB18030 / GBK）与 Excel（`.xlsx` / `.xls`）原始答卷。
   - **题型与元数据智能识别**：自动剥离问卷星等平台导出的系统元信息列（`序号`、`提交答卷时间`、`所用时间`、`来源`、`来源详情`、`来自IP`），精准识别单选题、多选题、量表题、数值题、NPS 题与开放文本题，支持人工微调覆盖。
   - **自适应质控与具体问题具体分析**：缺失时长列或量表列时自动跳过对应质控规则并明示原因；单题分析按题目与题型驱动（仅展示与当前题型匹配的统计表与图表，开放文本不足 10 条自动停用词云避免失真）；交叉分析支持选定「行变量 × 列变量」后实时计算显著性（$\chi^2$ / 列比例 $z$ / Welch $t$ / ANOVA / 相关回归）与效应量；专项模型严格按可用性矩阵动态解锁，不满足数据条件的模型不进入导航，绝不生成合成数据。

2. **全站一致的五套主题与原生深色系统 (`theme.py`, `.streamlit/config.toml`)**
   - 内置 5 套全站主题：**`暖纸杂志`**（默认 `#F7F2EA`）、**`墨蓝学术`**、**`纯白极简`**、**`深空夜读`**（原生全暗色 `#1E242E`）、**`薄荷清新`**。
   - 统一覆盖 `.stApp` 主画布、侧边栏、顶部状态栏、Glide DataGrid 数据表格、输入框、下拉选择器、按钮、指标卡、结论横幅与全部图表；所有文字与各级背景表面的对比度均满足 **WCAG AA ($\ge 4.5:1$)**。
   - 界面明示逐图专属配色（`chart_palettes.py`）与主题配色的协同规则，切换主题不丢失已上传数据、当前模块或单图格式设置。

3. **内部出版级图型库与四件套导出 (`charts_*.py`, `chart_utils.py`)**
   - 内置 48 种标准图型（49 张核心图 + 2 张扩展文本图）供各分析模块按需调用。
   - 每张图表遵循「口径副标题 → 动态结论主标题 → 图表主体 → 统计检验与样本脚注」四层结构，支持一键下载：
     - **高清 PNG**（宽度 $\ge 2400\text{px}$，主题色不透明底色）
     - **可编辑矢量 SVG**（`svg.fonttype = 'none'`，保留完整 `<text>` 节点）
     - **源数据 CSV**（`UTF-8-SIG` 编码，Excel 直接打开不乱码）
     - **矢量 PDF**（适合学术论文与印刷排版）

4. **手动格式面板与 AI 自然语言改图助手 (`ai_edit.py`)**
   - 支持标题/副标题覆盖、排序切换、Top N 筛选、配色切换、目标项高亮、参考线与字号缩放。
   - 支持 **17 个白名单真实改图动作**（含 5 步历史撤销栈与一键重置），严格拦截非法指令，绝不篡改底层统计数值。

5. **按需勾选的自适应可编辑报告导出 (`ppt_report.py`)**
   - 导出前自动盘点当前数据集实际支持的章节清单供用户勾选，仅生成真实数据支持的分析页与图表。
   - 16:9 宽屏 PPTX 同时内嵌 **原生可编辑 PowerPoint 图表**、**`svgBlip` 双层可解组矢量 SVG** 及 **备注栏 Markdown 源数据表**；Word 报告同步主题色并在文末附完整图表源数据表。

## 二、运行与自动化验收自检

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 运行统计与系统功能基准自检（A1–A18 与 S1–S8 共 26 项）
python self_check.py --stage all

# 3. 启动在线分析工作台
streamlit run app.py
```
